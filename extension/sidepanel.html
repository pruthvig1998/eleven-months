Eleven MonthsOn-device model: checking

Runs on this device only: fixed rules and Chrome's built-in Gemini Nano. This extension makes no cloud calls. When a clause needs a second opinion, "Full scan" opens the web app, where it can be masked and checked by cloud Gemini under App Check. The text goes in the address fragment, which the browser does not send to the server. A screening aid, not legal advice.
